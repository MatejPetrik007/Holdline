# Test vectors

Generated by `node tools/hl-vectors.mjs` from the reference codec. `node tools/hl-vectors.mjs --check` fails when these files are stale; CI runs it.

**Every key here is a throwaway**, derived from a public seed string in the generator. The private halves are in the files on purpose, so that anyone can produce new test messages. Never pin, provision or deploy anything from this directory.

- `vectors.json`: for JavaScript, TypeScript, Python, Rust.
- `vectors.txt`: the same content as `dotted.key = value` lines. Strings and byte strings are hex, numbers are decimal, `x.# = n` gives an array length.

Contents: two roots (CZ, PL), key bulletins including an older one (rollback) and a newer one that revokes a key, a provisioning bundle, alerts in one, two and three languages, a CANCEL, an FAQ entry, one encrypted question with its reference, a full ML-KEM-768 + X25519 key agreement, negative cases with the result a unit must return, and the topology of the website's blackout demo.
